# POC-31 正式产物上传

- [x] 只读取 Cospec Run manifest 中明确登记的 `kind=file` 正式产物，不扫描 `outputs/` 猜测文件。
- [x] 阶段结束后同步新增产物，Run 结束时再次同步兜底。
- [x] 入队时核对文件类型、大小和 SHA-256，并冻结到 Collector 待上传目录。
- [x] 单文件上限为 20 MiB；超限、内容变化和不可读取均留下明确状态，不静默跳过。
- [x] Collector 状态持久化，网络失败后随扫描周期使用相同 upload ID 重试；产物失败不阻止 JSONL 继续上传。
- [x] 服务端提供独立 multipart 接口，按 SHA-256 不可变保存并幂等关联 Run、Skill、attempt。
- [x] 提供带鉴权的 Run 产物列表与下载接口，响应禁止缓存且强制附件下载。
- [x] Run 详情页展示正式产物名称、所属 Skill、类型、大小、上传时间和下载入口。
- [x] 产物携带不含本机绝对目录的 `outputs/...` 逻辑路径，Run 详情按该路径展示可展开目录树。
- [x] 自动化测试覆盖冻结、重复同步、超限、HTTP 幂等、鉴权、持久存储、列表及下载。

- [x] Linux 环境真实进程链路通过；Windows 留待最终实机验收。

## 口径

- 上传的是 manifest 已登记的正式文件，不包括章节草稿、日志、临时文件和未登记附件。
- 外部类型产物只保留原有 manifest 记录，不抓取远端内容。
- 产物正文当前不参与运营指标解析，也不做在线预览、全文搜索或质量评价。
- 同一内容在服务端按 SHA-256 复用物理文件，Run 与版本关系仍分别保存。
