# POC-13 Collector 扫描频率调整

> 状态：已完成。目标是匹配“最终可靠上传”而非实时遥测的使用场景。

## 执行项

- [x] 默认后台扫描周期由 1 秒调整为 5 分钟；
- [x] `ensure` 建立关联后立即安排一次扫描，不等待后台周期；
- [x] `finish` 继续立即补传结束边界；
- [x] 手工 `scan` 继续立即执行；
- [x] 上传失败后保留 pending upload，等待下一次后台周期，不新增退避状态；
- [x] 提供仅用于测试或受控部署覆盖的扫描周期环境变量；
- [x] 自动化测试使用短周期，不实际等待 5 分钟；
- [x] 更新运行和可观测性文档。

## 验证结果

- 默认常量验证为 300,000 ms；
- Collector CLI 集成测试通过环境变量使用 50 ms 周期；
- 故障恢复测试通过依赖注入使用 100 ms 周期；
- 2026-09-01：类型检查和 31/31 自动化测试通过。
