- [x] JWT 缺失、过期或字段不可用时保持身份未知，不阻断工作流。
- [x] 只向 Collector 传工号和姓名，不传 JWT、Cookie 或 Token。

## 当前边界

- 当前只处理工号和姓名；部门字段已验证可得，但尚未接入 Run。
- IPD 返回的姓名按原值使用，不自行删改姓名中的工号后缀。
- 人员明细用于覆盖分析和问题排查，不做个人排名或绩效评价。
