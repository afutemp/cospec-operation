# POC-04：不可变原始存储与解析状态

> 状态：已完成（2026-09-01）。依赖 POC-03 已完成。

## 实施项

- [x] 使用服务端 SQLite 保存上传、连续性和解析状态；
- [x] 原始块按不可变路径原子写入服务端文件系统；
- [x] 原始内容可靠落盘且元数据事务提交后才返回 accepted；
- [x] 服务重启后保持幂等、next offset 和 hash 链；
- [x] 重复路径必须核对 hash，不静默覆盖；
- [x] 识别文件已落盘但数据库未提交的孤儿文件；
- [x] 解析状态初始为 `pending`，为 POC-05 提供读取入口。

## 验收

- [x] accepted 后重启服务，原始字节和元数据仍存在；
- [x] 重传返回 already_accepted，不新增文件或记录；
- [x] DB 或文件写入失败不返回 accepted；
- [x] offset/hash 冲突在重启前后行为一致；
- [x] 原始文件与登记 SHA-256 一致；
- [x] 仓库不包含运行期数据库、原始块或凭据。
