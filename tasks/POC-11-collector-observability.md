# POC-11 Collector 异常状态与滚动日志

> 状态：已完成。仅处理客户端 Collector 可观测性。

## 执行项

- [x] 状态 JSON 保存最近扫描、最近上传成功、连续失败、最近错误与恢复时间；
- [x] `status` 返回当前诊断摘要；
- [x] `logs/collector.jsonl` 持续记录启动、停止、Run、上传、失败和恢复事件；
- [x] 日志单文件上限 5 MiB，保留 2 个历史文件；
- [x] 日志不包含原始正文、token、请求头、工具内容、完整堆栈或绝对源路径；
- [x] 后台扫描异常不再静默丢失；
- [x] 验证失败、连续重试、恢复和重启后的状态保留；
- [x] 验证日志轮转。

## 验证结果

- 模拟接收端连续失败后，状态累计失败次数，日志保留每次 `scan_failed`；
- 接收端恢复后，同一 pending upload 成功续传，状态清除当前错误并写入 `recoveredAt`；
- daemon 重启后可读取上一次成功和恢复状态；
- 小容量自动化测试验证当前文件加 2 个历史文件的轮转边界；
- 2026-09-01：类型检查、`git diff --check` 和 30/30 自动化测试通过。
