# POC-20 统计 Run 时长与资源分布

## 用户能看到什么

- [x] 普通一次 Run 和较重一次 Run 的记录时间跨度；
- [x] 普通一次 Run 的消息数；
- [x] 普通一次 Run 的输入、输出 Token；
- [x] 普通一次 Run 的工具调用次数；
- [x] 普通一次 Run 中工具实际占用的经过时间；
- [x] 整体以及按 Agent、版本、模型查看上述数据。

“普通一次”使用 P50，“约九成 Run 不超过”使用 P90，同时返回平均值和数据覆盖率。

## 口径约束

- [x] Run 时长只是 JSONL 首末有效时间的跨度，包含用户停顿，不称为纯执行耗时；
- [x] 输入和输出 Token 分开统计，不自行拼成总 Token；
- [x] 缺失数据不按零参与平均值、P50 或 P90；
- [x] 已完成解析且没有消息/工具调用时，消息数和工具数可以明确为零；
- [x] 工具耗时只有在全部调用都能配对时间时才纳入 Run 分布；
- [x] 多模型 Run 分别进入相关模型组，模型组数量不可相加为总 Run 数。

## 验证

- [x] 自动化测试覆盖双 Agent、多模型、无时间记录、零工具和工具时间；
- [x] Codex 真实样本读取到 178 条消息、169 次工具调用及首末记录跨度；
- [x] Claude Code 真实样本读取到 1,354 条消息、433 次工具调用及首末记录跨度；
- [x] 42/42 项自动化测试和 TypeScript 类型检查通过。
