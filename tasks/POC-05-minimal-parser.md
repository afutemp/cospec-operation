# POC-05：Codex JSONL 最小解析器

> 状态：已完成（2026-09-01）。依赖 POC-04 已完成。

## 实施项

- [x] 从 SQLite `pending` 队列读取不可变原始块；
- [x] 读取前复核原始块 SHA-256；
- [x] 逐行解析 JSON，统计合法、非法和未知类型；
- [x] 提取顶层记录类型数量与明确时间范围；
- [x] 非法行只记录行号、byte offset 和错误码；
- [x] 结果携带解析器版本并幂等写入 SQLite；
- [x] 更新 `completed`、`completed_with_errors` 或 `failed` 状态；
- [x] 不保存正文、工具参数或工具输出副本。

## 验收

- [x] 合法样本得到准确行数、类型分布和时间范围；
- [x] 非法单行不阻断其余行解析；
- [x] 未知类型被计数但不作为错误；
- [x] hash 不匹配或文件不可读记为 failed；
- [x] 服务重启后 pending 队列和解析结果保持一致；
- [x] 同一解析器版本重复执行不产生重复结果。
