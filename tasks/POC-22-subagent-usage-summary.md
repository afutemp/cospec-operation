# POC-22 汇总子代理使用与资源分布

## 范围

只统计新版 Collector 明确标记 main/subagent 的 Run。开发阶段旧格式测试数据直接排除，不迁移，也不解释为“没有使用子代理”。

## 用户能看到什么

- [x] 有多少 Run 使用了子代理，以及使用比例；
- [x] 一次 Run 通常启动多少个子代理；
- [x] 子代理最大层级和会话记录跨度；
- [x] 子代理消息、输入/输出 Token、工具调用和工具经过时间；
- [x] 子代理资源占整个 Run 资源的比例；
- [x] 按 Agent、Agent 版本和子代理模型拆分；
- [x] 平均值、P50、P90和缺失数据覆盖范围。

## 口径

- [x] 新版 Run 没有发现子代理时，可以明确计为 0；
- [x] 旧格式 Run 完全排除，并返回排除数量；
- [x] Token 缺失不补零；
- [x] 总资源为 0 时不计算资源占比；
- [x] 多模型子代理 Run 进入每个相关模型组，模型组不可相加；
- [x] 子代理仍只归属 Run，不归属 Skill。

## 验证

- [x] 自动化测试覆盖新版有子代理、新版无子代理和旧格式 Run；
- [x] 验证消息、Token、工具耗时及资源占比；
- [x] 验证 Codex、Claude Code、版本和模型拆分；
- [x] 46/46 项自动化测试和 TypeScript 类型检查通过。

接口说明见 [只读查询 API](../docs/query-api.md)。
