# POC-26 周度使用深度与 Skill 资源归属

## 目标

在不增加客户端采集字段、不读取业务正文的前提下，用现有匿名终端、Run、Skill 边界和宿主资源事实补充领导周报与优化分析。

## 验收

- [x] 按查询周期统计活跃匿名终端、每终端 Run 数和 1 次／2～3 次／4 次以上频次分层。
- [x] 有开始时间的查询可区分此前已被观测的持续使用终端与本期首次观测终端。
- [x] “终端”不解释为人员，“首次观测”不解释为新增用户。
- [x] 完整 Skill 区间可归属 Token、工具调用、明确失败和子代理。
- [x] 嵌套 Skill 同时返回包含子 Skill 的资源和只归给最内层 Skill 的自身资源；汇总使用自身资源避免重复。
- [x] 缺少时间戳、缺少完整 Skill 边界的事实不强行归属，并返回归属覆盖率。
- [x] Run 详情与运营总览完成展示和接口联调。
- [x] 自动化测试覆盖持续使用、首次观测和嵌套 Skill 去重。

## 口径

持续使用终端指本期有 Run 且在本期开始前已有符合当前筛选条件的 Run 的匿名终端。只有查询明确传入 `from` 时才计算；全量查询返回不可得。

资源使用事实自身的 JSONL 时间戳落在完整 Skill START/END 区间内时才能归属。父子 Skill 嵌套时：`inclusive` 表示包含子 Skill，`self` 将每条资源只归到最内层区间。运营汇总采用 `self`。

## 实际联调

使用此前通过 Collector 上传的真实 Claude Code Run `9d55ba5c-27a3-4a1b-9681-300f1002ffbf` 联调：本周查询返回 2 个活跃匿名终端、每终端 1 个 Run、2 个首次观测终端；`product-planning-requirement-clarification` 自动归属 33 条 Token observation、63239 输入 Token、35136 输出 Token、15 次工具调用和 1 次明确失败。Run 详情展开后可分别读取自身与包含子 Skill 的资源。

自动化夹具另外覆盖父子 Skill 嵌套：父 Skill 汇总扣除了子 Skill 的 Token、工具失败和子代理，单次执行的 `inclusive` 仍保留完整总量。
