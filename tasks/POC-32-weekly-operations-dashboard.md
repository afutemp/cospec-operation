# POC-32 领导周报与重点 Skill 运营视图

- [x] 总览默认进入“领导周报”，并与“运营排查”分开。
- [x] 周报首屏展示使用人数、工作流运行数、已结束完成率、重点 Skill 执行量和正式产物数。
- [x] 使用人数、工作流数和 Skill 执行量按同长度上一周期展示环比；完成率展示上期值。
- [x] 展示大／小／自定义工作流、终态和阶段漏斗。
- [x] 重点 Skill 展示使用人数、涉及 Run、执行次数、成功失败、活跃 P50、等待用户和工具失败。
- [x] 正式产物展示数量、有产物工作流、覆盖率和产物角色分布。
- [x] 展示人员、工号、产线和工作流数量。
- [x] 人员、产线、Agent 和版本筛选同时作用于周报与重点 Skill 数据。
- [x] 技术资源、版本观察、无活动 Run 和详细等待指标下沉到“运营排查”。
- [x] Chromium 端到端验证周报、运营排查、Run 下钻与产物下载。

## 口径

- 默认按自然周查看；“上期”是当前选择区间之前的同长度区间。
- 使用人数来自 Run 启动时的 IPD 人员快照，未知身份不计入人数。
- 完成率只计算已经明确结束的工作流，进行中不进入分母。
- Skill 活跃时长剔除明确等待用户回复的时间。
- 所有对比只描述观察结果，不解释为版本或工具造成的因果变化。
