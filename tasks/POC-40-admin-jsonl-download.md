# POC-40 管理员下载原始 JSONL

- [x] 服务端支持独立管理员 Token，管理员同时具有普通查询权限
- [x] 普通用户下载原始 JSONL 返回 403
- [x] Run 详情按主会话、子代理来源和文件代次列出已采集 JSONL
- [x] 管理员可下载该 Run 实际采集到的 JSONL 片段
- [x] 多块按 offset 顺序还原，下载前逐块复验 SHA-256
- [x] 文件名和来源接口不暴露客户端或服务端绝对路径
- [x] 页面不在线预览包含业务正文的 JSONL
- [x] 服务端集成测试和 Chromium 下载验收通过

管理员下载的是 Run 边界内已上传的数据，不包含客户端原会话文件在采集边界之外的内容。正式环境必须为普通查询与管理员下载配置不同 Token；后续接入 SSO 时将管理员权限映射到服务端角色。
