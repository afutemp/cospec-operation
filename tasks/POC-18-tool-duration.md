# POC-18 统计工具调用耗时

## 用户能看到什么

- [x] 一个 Run 调用了多少次工具；
- [x] 其中多少次可以算出耗时，以及数据覆盖率；
- [x] 一次工具调用通常需要多久（P50/P90）；
- [x] 所有工具耗时相加后的资源使用量；
- [x] 去除并发重叠后，Run 实际有多长时间处于工具执行中；
- [x] 按工具名称查看相同统计。

## 数据规则

- [x] 只用相同 `call_id` 的调用时间和结果时间，不读取工具正文；
- [x] 调用或结果缺失时记为不可计算，不补零；
- [x] 结果早于调用时记为异常区间，不参与耗时；
- [x] 调用和结果分属不同上传块时仍可关联；
- [x] 并发区间合并，避免重复计算实际经过时间。

## 验证

- [x] 自动化测试覆盖完整、缺失、反向时间和并发重叠，共 41/41 项通过；
- [x] Codex 真实样本 169/169 次工具调用可计算耗时；
- [x] Claude Code 真实样本 433/433 次工具调用可计算耗时。

字段说明见 [宿主资源与工具事实 0.2](../docs/host-resource-facts-v0.2.md)。
