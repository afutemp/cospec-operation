# POC-27 Skill 交互、无活动 Run 与版本对比

## 目标

继续使用已经上报的原始 JSONL 和解析事实，补充可直接用于周报和优化排查的指标，不修改 Cospec，不读取正文。

## 验收

- [x] Skill 返回等待用户次数、单次等待 P50/P90、免等待执行比例和等待占总历时比例。
- [x] 总览按 Skill 展示等待次数、累计等待和免等待比例。
- [x] 返回 24/48 小时没有 JSONL 活动的 Run，并可下钻到 Run 详情。
- [x] 无活动状态只作为排查信号，不改写工作流业务状态。
- [x] 按 Cospec 插件版本和 Agent 版本比较 Run、匿名终端、Skill 时长与等待、Token、工具失败、子代理和上下文压缩。
- [x] 每个版本强制展示样本 Run 数，注明只做观察性比较，不声明因果。
- [x] 自动化测试和真实数据浏览器联调通过。

## 口径

等待次数只统计同时观察到 Agent 可见消息和下一条人工输入的完整区间。工具结果、Skill 注入内容和压缩摘要不计为人工输入。

无活动 Run 使用服务端查询时刻减去 Run 最后一条 JSONL 事件时间。它不等于失败、中断或用户放弃。

版本表现使用当前筛选范围内的事实聚合。不同版本的用户和任务构成可能不同，因此只提供观察性对比，并始终返回样本量。

## 实际联调

使用现有服务端真实数据完成浏览器联调：本期样本包含 Cospec `1.1.85` 的 2 个 Run，并能分开显示 Claude Code `2.1.220` 和 Codex `0.137.0`。Claude Code 样本展示 1 次明确工具失败及对应状态覆盖率；Codex 样本没有完整 Skill 时长时显示“暂无数据”，没有误显示为 0。真实样本当前没有人工等待和 24 小时无活动 Run，因此分别显示 0 次和 0 个；构造测试覆盖了 60 秒人工等待及历史无活动数据。
