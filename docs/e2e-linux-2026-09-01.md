# Linux 真实端到端验收记录

> 日期：2026-09-01。Windows 实机验收不在本记录范围内。

## 链路

使用当前真实 Codex Session ID，通过独立临时目录运行：

```text
真实 Codex JSONL
→ Collector daemon
→ multipart HTTP
→ Fastify
→ 不可变原始文件 + SQLite
→ pending Worker
→ parser 0.1.0
→ 查询 API
```

## 结果

- Session 通过显式 ID 与 JSONL `session_meta.payload.id` 匹配；
- Run 起点为 `ensure` 时的完整行边界，不上传此前历史内容；
- `finish` 前后累计确认16个连续块、53544字节；
- 最终 Run 区间为33条合法 JSONL 记录；
- 16个块均可靠落盘、`rawPresent=true` 并解析为 `completed`；
- active parser version 为 `0.1.0`；
- `finish` 后继续产生真实 Agent 活动并等待多个扫描周期，块数和 end offset 不再变化；
- 服务端停止并从同一存储目录重启后，块数、字节数、结束 offset、解析汇总和 active version 保持一致；
- Collector 与服务端正常关闭，无遗留进程。

本机 shell 配有代理，curl 查询 localhost 时需使用 `--noproxy 127.0.0.1`；Collector 的 Node.js fetch 直连正常。

## 数据处置

验收使用隔离的 `/tmp` 目录。结束后已删除其中的真实 JSONL 块、SQLite、Collector 状态和临时测试 Token；仓库仅保留不含正文、绝对源路径和凭据的本记录。
